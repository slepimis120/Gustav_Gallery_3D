## Project Description

The "Gustav" project is a 3D interactive scene developed using **OpenGL**, showcasing an art exhibition with dynamic lighting and models. The focus of the project was to work on realistic rendering techniques and user interaction within a 3D environment. It is implemented in **C++** using **Visual Studio** as the development platform.

### Key Features

- **OpenGL Rendering**: Utilizes OpenGL for rendering 3D graphics with perspective projection to maintain scene visibility.

- **Camera Control**: 
  - Implements a first-person camera with smooth navigation controls.
  - Supports rotation, movement, and zooming while preventing collision with walls.

- **Dynamic Lighting**: 
  - Features a Blinn-Phong lighting model with point lighting for realism.
  - Includes a color-changing light source above the angel statue.

- **3D Models and Textures**: 
  - Angel statue model that rotates based on user interaction.
  - Uses transparent textures for displaying student information and various wall materials (golden squares, wood).

- **User Interaction**: 
  - Toggleable flashlight that follows the camera's position.
  - Switch functionality to control room lighting based on camera proximity.

- **Display Modes**: 
  - Ability to switch between Wireframe and Polygon display modes for debugging and visualization.


## Technologies

- Programming Language: **C++**
- Development Environment: **Visual Studio**
- Graphics API: **OpenGL**
